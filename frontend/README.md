# ALTER AI — интерфейс

1. Backend іске қосыңыз (жоба түбірінен): `py -m uvicorn backend.main:app --reload`
2. `frontend/index.html` файлын екі рет шертіп, Chrome-да ашыңыз.
3. **Get Started** түймесін басып, **Research Matching** бетін ашыңыз да, **Live AI Team Builder** блогын қолданыңыз.
   Ол сұранысты backend-ке жібереді (http://127.0.0.1:8000): жеке агенттер жауап береді, CSP команданы жинайды, Bayes бағасы үміткерлерді сұрыптайды.

Басқа беттер (Hackathon, Internship, Messages, My AI Agent, Settings) тұрақты демо-деректерді қолданады.
Барлық профильдер мен сөйлесулер ойдан шығарылған. Профиль мен баптаулар браузерде сақталады.
Интернет тек қосымша Inter шрифтін жүктеу үшін қажет.
